# HumaForge

### End-to-End Benchmark Generation and Evaluation for Full-Size Humanoid Robots

**From natural-language requests to interactive assets, task environments, and executable evaluation.**

HumaForge is a research project for building and evaluating humanoid robot benchmarks. It brings asset generation, scene construction, task design, and scoring into one workflow, with editable intermediate outputs and feedback across stages.

We are preparing our paper and open-source release. **Stay tuned for the paper, code, benchmark tasks, and assets!**

## What we are building

- **End-to-end benchmark generation.** Turn task requirements into assets, scenes, task specifications, and scoring programs. Generate new interactive assets when existing libraries do not meet a task's needs.
- **Editable generation workflows.** Revise intermediate outputs and track their dependencies so that related scenes, bindings, and evaluation rules can be updated and checked together.
- **Humanoid task evaluation.** Evaluate task progress, required actions, and conditions that must hold over time. Account for whole-body contact and support, and assess task completion separately from execution quality.
- **A 30-task humanoid benchmark.** Cover manipulation, locomotion, and whole-body interaction with shared evaluation protocols and reusable task resources.

## Paper and open-source release

**We will open-source HumaForge.** Code and resources will be published progressively as they are prepared for release, with the main release planned following paper acceptance.

The planned release includes:

- Benchmark generation tools and configuration examples
- Humanoid task definitions, scenes, and evaluation code
- Generated assets and asset preparation utilities
- Documentation for setup, reproduction, and adding new tasks

Third-party assets will retain their original attribution and licenses. Resources that cannot be redistributed will be accompanied by source links or preparation instructions.

This repository currently serves as the project announcement. The implementation, benchmark files, and paper are not yet available here. Release details and usage instructions will be added as they become available.
